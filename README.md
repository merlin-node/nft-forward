# nft-forward

基于 nftables 的端口转发管理脚本(Debian 13)。

## 安装

```bash
cd ~ && wget https://github.com/merlin-node/nft-forward/archive/refs/heads/main.zip && unzip main.zip && cd nft-forward-main && sudo bash install.sh
```

没装 unzip 先装:`sudo apt install -y unzip`

## 使用

```bash
zf
```

## 更新

进菜单按 `10` 即可在线更新。

## 卸载

进菜单按 `9` 即可一键卸载。
